# mdoc

`mdoc` — небольшой конвертер Markdown-документов в HTML и PDF на Perl. Он использует собственный парсер и поддерживает часть синтаксиса CommonMark вместе с расширениями:
- таблицами,
- задачами,
- сносками,
- индексами,
- модификаторами размещения.

Полная совместимость с CommonMark и GFM не заявляется.

Для запуска из корня проекта:

```sh
mkdir -p test/result
./md test/toc.md test/result/toc.html
./md test/toc.md test/result/toc.pdf
```

Формат выбирается по расширению файла назначения; при необходимости его можно задать через `-t html` или `-t pdf`. HTML по умолчанию выводится фрагментом, который можно встроить в страницу. PDF требует дополнительных модулей Perl и доступных рендереру шрифтов.
