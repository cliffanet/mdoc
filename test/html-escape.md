# Заголовок с <tag> & символом

\toc

Обычный текст: <b class="test">тег</b>, <script>alert(1)</script>, 2 < 3 и &amp;.

Вложенный стиль: **<span>жирный & текст</span>** и [ссылка с <em>тегом</em>](https://example.com/?a=1&b=2).

Экранированные скобки: \<tag\> и буквальная мнемоника &lt;tag&gt;.

Строчный код: `<i title="x&y">код</i>`.

> Цитата с <q>тегом</q> и &.

- Пункт списка с <u>тегом</u>.

| Заголовок <tag> | Значение |
| :------------- | :------- |
| <em>тег</em>   | A & B    |

```html
<div class="box">A & B</div>
```
