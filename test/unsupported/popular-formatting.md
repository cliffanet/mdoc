СТРОЧНЫЙ И БЛОЧНЫЙ КОД

Двойные обратные кавычки позволяют поместить одиночную: ``код с ` внутри``.

Тройные обратные кавычки внутри строки: ```код с `` парой кавычек внутри```.

Код с пробелами по краям: `` код ``.

~~~javascript
const message = 'Блок с ограждением из тильд';
~~~

````markdown
Четыре кавычки должны позволять вложить обычное тройное ограждение:
```
вложенный блок
```
Текст после вложенного блока должен остаться во внешнем блоке.
````

ГРАНИЦЫ ВЫДЕЛЕНИЯ И GFM-ЗАЧЁРКИВАНИЕ

Пробелы не разрешают курсив: a * b * c.

Пробелы около границ оставляют маркеры буквальными: ** жирный ** и * курсив *.

**Жирный текст начинается, *курсив пересекает его завершение** и заканчивается здесь*.

~~Пересекающееся зачёркивание с **жирным текстом~~ внутри**

Одинарные тильды в GFM обозначают зачёркивание: ~текст~.
