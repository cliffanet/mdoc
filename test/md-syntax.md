## Текст и строчные элементы

Обычный текстовый абзац может занимать
несколько строк исходного документа.

\center

Горизонтально центрированный текстовый абзац.

\vcenter

Вертикально центрированный текстовый абзац в PDF.

\center
\vcenter

Горизонтально и вертикально центрированный текстовый абзац в PDF.

Жирный текст задаётся как **двумя звёздочками**, так и __двумя подчёркиваниями__.

Курсив задаётся как *одной звёздочкой*, так и _одним подчёркиванием_.

Зачёркнутый текст задаётся ~~двумя тильдами~~.

Подчёркнутый текст задаётся ++двумя плюсами++.

Выделение маркером задаётся ==двумя знаками равенства==.

Строчные элементы могут быть вложенными: **жирный текст с _курсивом_ внутри**.

~~Зачёркивание с **жирным текстом** и *курсивом* внутри~~.

**Жирный текст с ~~зачёркиванием~~ внутри**.

*Курсив с ~~зачёркиванием~~ внутри*.

==Выделение с **жирным текстом** внутри==.

**Жирный текст с ==выделением маркером== внутри**.

++Подчёркнутый текст с **жирным текстом** внутри++.

~~Зачёркнутый ==выделенный ++подчёркнутый текст++==~~.

==Выделение с ++подчёркиванием и `строчным кодом`++ внутри==.

~~Зачёркивание со [ссылкой](https://example.com) и `строчным кодом` внутри~~.

[Ссылка с ~~зачёркиванием~~, ++подчёркиванием++ и ==маркером==](https://example.com).

Длинное ~~зачёркнутое и ==выделенное маркером с ++подчёркиванием++ содержимое==, которое
продолжается на следующей строке и должно корректно переноситься по строкам PDF~~.

Строчный код: `my $value = 1;`.

## Экранирование служебных символов

Экранированные звёздочки не включают курсив: \*не курсив\*.

Экранированные двойные маркеры не включают форматирование:
\*\*не жирный текст\*\*, \_\_не жирный текст\_\_, \~\~не зачёркнутый текст\~\~,
\+\+не подчёркнутый текст\+\+ и \=\=не выделенный текст\=\=.

Экранированные обратные кавычки не включают код: \`не код\`.

Экранированные скобки не создают ссылку: \[не ссылка\]\(https://example.com\).

Все экранируемые ASCII-знаки пунктуации:
\! \" \# \$ \% \& \' \( \) \* \+ \, \- \. \/ \: \; \< \= \> \? \@ \[ \\ \] \^ \_ \` \{ \| \} \~.

Обратная косая черта перед неслужебными символами сохраняется: \A, \3, \→ и \ пробел.

*Курсив с \* буквальной звёздочкой внутри*.

Экранированная обратная косая черта перед форматированием: \\*курсив*.

[Ссылка с экранированной \] закрывающей скобкой](https://example.com/a\)b?x=1\&y=2).

Изображение с экранированными URL и заголовком:
![Описание](images/example\).png "Заголовок с \"кавычкой").

Строчный код сохраняет обратные косые черты: `\* \| \[ \]`.

Экранированные блочные маркеры остаются текстом:

\# Не заголовок

\- Не элемент списка

\* Не элемент списка

\+ Не элемент списка

1\. Не элемент нумерованного списка

1\) Не элемент нумерованного списка

\> Не цитата

\--- Не горизонтальная линия

\`\`\` Не блок кода

\[example]: https://example.com "Не ссылочная метка"

## Списки

* Маркированный список со звёздочкой
* Второй элемент списка со звёздочкой

- Маркированный список с дефисом
- Второй элемент списка с дефисом
    * Вложенный маркированный список
    * Второй вложенный элемент

+ Маркированный список с плюсом
+ Второй элемент списка с плюсом
    3) Вложенный нумерованный список со скобкой
    4) Второй вложенный нумерованный элемент

1. Первый элемент нумерованного списка
2. Второй элемент нумерованного списка
    5. Вложенный нумерованный список с явно заданным номером

1) Первый элемент нумерованного списка со скобкой
2) Второй элемент нумерованного списка со скобкой
    + Вложенный маркированный список с плюсом
    + Второй вложенный элемент с плюсом

- [ ] Невыполненная задача
- [x] Выполненная задача
- [X] Выполненная задача с прописной отметкой
- [~] Задача в промежуточном состоянии
- [ ] Задача с **форматированием** и [ссылкой](https://example.com/task)
    + [ ] Вложенная невыполненная задача
    + [x] Вложенная выполненная задача

1. [ ] Нумерованная невыполненная задача
2. [~] Нумерованная задача в промежуточном состоянии

print '\* \| \[';

## Неформатированные текстовые блоки

### Отступ в четыре пробела

    Текстовый блок с отступом в четыре пробела.
    **Разметка** внутри него не обрабатывается.
    \* \| \[ сохраняются вместе с обратной косой чертой.

### Отступ в одну табуляцию

	Текстовый блок с отступом в одну табуляцию.
	`Разметка` внутри него не обрабатывается.
