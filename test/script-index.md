# Индексы x^2^ и H~2~O

\toc

Формула без математического расширения: H~2~O и x^2^.

Кириллица: x^степень^ и H~индекс~O.

**Жирный H~2~O**, *курсивный x^2^* и ==выделенный H~2~O==.

Верхний индекс с *курсивом*: x^*ab*^; нижний с **жирным**: H~**2**~O.

Разные индексы вкладываются: x^H~2~O^ и H~x^2^~O.

Пробел допустим лишь с экранированием: x^a\ b^ и H~a\ b~O.

Экранированный маркер внутри индекса: x^a\^b^ и H~a\~b~O.

Ссылка с индексом [x^2^](https://example.com) и индекс со [ссылкой](https://example.com): x^[a](https://example.com)^.

Зачёркнутое ~~слово~~ рядом с H~2~O.

Буквальные маркеры: \^2\^, \~2\~, `x^2^`, `H~2~O`.

Ошибочные маркеры: x^^, H~~O, x^не закрыт, H~не закрыт, x^два слова^.

Незакрытый индекс после переноса: x^первая
вторая^ остаётся буквальным текстом.

Длинная строка для проверки PDF-переноса: H~первый~O x^второй^ H~третий~O
x^четвёртый^ H~пятый~O x^шестой^ H~седьмой~O x^восьмой^ H~девятый~O
x^десятый^ H~одиннадцатый~O x^двенадцатый^ H~тринадцатый~O x^четырнадцатый^.

| Формула | Значение |
| :------ | :------- |
| H~2~O   | x^2^     |

Индекс рядом со сноской x^2^[^script-note].
