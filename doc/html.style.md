# Общие правила форматирования

- Текст состоит из абзацев (блоков)
- Абзацы (блоки) могут вкладываться один в другой
- Текст внутри абзаца (блока) может иметь стилистическое форматирование
- Стилистическое форматирование может быть любой глубины вложенности
- Внутри стилистического форматирования не может быть тегов абзацев (блоков)

- На любой странице внутри может быть только один блок <div id="content"></div>
- Указанный блок содержит основную информативную часть страницы
- Внутри такого блока содержимое может содержать только перечисленное ниже форматирование
и только по описанным выше правилам.
- Никаких других вариантов html-тегов внутри данного блока быть не может.
- Допустимо до блока <div id="content"></div> и после него размещать неосновную информативную часть
- Желательно до блока <div id="content"></div> и после него размещать только одинаковый для всех страниц код (например, навигацию по сайту)
- Во всех перечисленных html-тегах могут быть только указанные в них классы. Никаких других классов и каких-либо параметров у html-тегов быть не должно.

- Во всех ниже перечисленных html-тегах могут быть только указанные в них классы. Никаких других классов и каких-либо параметров у html-тегов быть не должно.
- Текст состоит из абзацев (блоков)
- Абзацы (блоки) могут вкладываться один в другой
- Текст внутри абзаца (блока) может иметь стилистическое форматирование
- Стилистическое форматирование может быть любой глубины вложенности
- Внутри стилистического форматирования не может быть тегов абзацев (блоков)

## Абзацы (блоки)

- Простой текстовый абзац

    <p>Текст</p>

    Тег <p></p> не может вкладываться напрямую сам в себя. Только внуть каких-либо других блоков.

- Заголовки

    <h1>Текст</h1>
    <h2>Текст</h2>
    <h3>Текст</h3>
    <h4>Текст</h4>
    <h5>Текст</h5>
    <h6>Текст</h6>

    Заголовки могут находиться только на верхнем уровне вложенности и не могут быть вложены
    ни в какие другие блоки.

- Горизонтальная линия с заголовком над линией

    <h2 class="horizontal-line">Текст</h2>

- Горизонтальная линия

    <hr/>

- Выделенный блок с кодом программы (внутри не может быть вложенных стилей)

    <pre class="code"><code class="block">Текст</code></pre>

- Выделенный блок с простым неформатированным текстом (внутри не может быть вложенных стилей)

    <pre class="textblock"><code class="block"></code></pre>

- Выделенный блок цитаты (поддерживает абзацы и стили внутри)

    <blockquote></blockquote>

- Нумерованный список

    <ol><li value="1">Элемент списка</li><li value="2">Элемент списка</li></ol>

    Где в параметре value указан номер элемента списка.

- Простой список

    <ol><li>Элемент списка</li><li>Элемент списка</li></ol>

    И в простом, и в нумерованном списке, каждый элемент списка может содержать вложенные абзацы и стили.
    В каждом элементе списка, если это простой текст, в теги <p></p> оборачиваются абзацы, начиная со второго.
    Первый абзац в тэг <p></p> не оборачивается, но оборачивается в тег <div></div>.

- Таблица

    <table class="table1">
        <thead><th>Заголовок колонки 1</th><th>Заголовок колонки 2</th></thead>
        <tbody><tr><td>Колонка 1</td><td>Колонка 2</td></tr></tbody>
    </table>

    Тег <table> может содержать класс "table1" или "table2". Это две стилизации таблиц.
    
    - table1 - это классическая таблица
    - table2 - строки отделяются горизонтальными линиями, колонки отделяются пустым пространством без линий

    Внутри ячеек могут содержаться вложенные абзацы и стили.

    Выравнивание в ячейках по умолчанию по левому краю. Теги <th> и <tr> могут содержать классы
    для выравнивания текста: class="align-right" и class="align-center"

    Для таблиц table2 не может быть заголовка таблицы


## Текстовые стили внутри абзаца

Стили могут вкладываться один в другой

- Жирный текст

    <strong>Текст</strong>

- Наклонный текст

    <em>Текст</em>

- Inline-текст, выделенный в прямоугольник

    <code class="inline">Текст</code>

- Изображение

    <img src="ссылка" alt="описание" title="описание">

- Ссылка

    <a href="ссылка">Текст</a>
