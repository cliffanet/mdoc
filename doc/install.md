# Установка и запуск

`mdoc` запускается прямо из каталога проекта; отдельной сборки или установки самого конвертера нет. Для HTML нужен Perl и его стандартные модули. Для PDF дополнительно требуются Perl-модули `PDF::API2` и `LWP::UserAgent`, а также шрифты. Минимальная версия Perl проектом пока не установлена; после установки проверяйте работу командами ниже.

## Получение проекта и Perl

Склонируйте проект и перейдите в его каталог:

```sh
git clone https://github.com/cliffanet/mdoc.git
cd mdoc
```

Если Perl уже установлен, повторно устанавливать его не нужно. Проверить установку можно так:

```sh
perl -v
```

Примеры для трёх платформ:

### macOS

Установите Perl и `cpanm` через Homebrew ([формулы Perl](https://formulae.brew.sh/formula/perl) и [cpanminus](https://formulae.brew.sh/formula/cpanminus)):

```sh
brew install perl
brew install cpanminus
```

Убедитесь, что команды `perl` и `cpanm` используют одну установку Perl.

### Debian/Ubuntu

Установите Perl и `cpanm` ([пакет cpanminus в Debian](https://packages.debian.org/stable/cpanminus)):

```sh
sudo apt update
sudo apt install perl cpanminus
```

В других дистрибутивах Linux названия пакетов и команда пакетного менеджера могут отличаться.

### FreeBSD

От имени администратора установите Perl и `cpanm` ([каталог портов FreeBSD](https://cgit.freebsd.org/ports/tree/devel/Makefile)):

```sh
pkg install perl5 p5-App-cpanminus
```

Благодаря переносимому shebang исполняемый файл `md` использует `perl` из `PATH`.

Для PDF установите оба внешних модуля в выбранную установку Perl:

```sh
cpanm --from https://www.cpan.org PDF::API2 LWP::UserAgent
perl -MPDF::API2 -MLWP::UserAgent -e 'print "PDF modules OK\n"'
```

Опция `--from` задаёт HTTPS-зеркало: без неё `cpanm` может загружать код по HTTP ([рекомендация группы безопасности CPAN](https://security.metacpan.org/2024/08/26/cpanminus-downloads-code-using-insecure-http.html)). Если проверка не проходит после установки, сначала убедитесь, что `cpanm` устанавливал модули для того же `perl`, которым запускается конвертер. При установке модулей в пользовательский каталог может потребоваться настроить [`local::lib`](https://metacpan.org/pod/local::lib); не меняйте системные каталоги Perl только ради этого проекта. Для конвертации только в HTML `PDF::API2`, `LWP::UserAgent` и шрифты не нужны.

## Шрифты для PDF

PDF-рендерер ищет шрифты в системных каталогах и в папке `fonts/` корня проекта. Для полного набора стилей ему нужны файлы с точными именами:

- `Arial.ttf`
- `Arial Bold.ttf`
- `Arial Italic.ttf`
- `Arial Bold Italic.ttf`
- `PTMonoBold.ttf`

Если они не найдены в системных каталогах, создайте `fonts/` и поместите туда свои лицензированные TrueType-файлы с этими именами. Содержимое `fonts/` игнорируется Git и не распространяется вместе с проектом. На Linux и FreeBSD этот путь позволяет использовать PDF без macOS-каталогов шрифтов. Необязательно добавлять шрифты, если PDF уже успешно строится с установленными в системе файлами нужных имён.

## Пробный запуск

Из корня проекта выполните:

```sh
./md --help
mkdir -p test/result
./md test/toc.md test/result/toc.html
./md test/toc.md test/result/toc.pdf
```

Тип результата определяется по расширению файла назначения. Его можно указать явно:

```sh
./md -t html input.md output
./md -t pdf input.md output
```

Реализованы только `html` и `pdf`.

Без шаблона HTML представляет собой фрагмент разметки. Для полной страницы задайте `html-template` в начале Markdown-документа; образец шаблона и CSS находятся в `out.html` и `out.css`. Если HTML сохраняется в другой каталог, обеспечьте доступный из него путь к CSS. PDF создаётся на странице A4. Встроенные тестовые документы пишут результаты в `test/result`, который не добавляется в Git.

## Настройки и пути

Командная строка:

- `-h`, `--help` — показать справку.
- `-t`, `--type` — выбрать `html` или `pdf`, независимо от расширения назначения.
- `-r`, `--root-dir` — указать базовый каталог для локальных изображений в PDF; по умолчанию используется каталог исходного Markdown-файла.
- `-b`, `--base-uri` — добавить префикс к относительным внешним ссылкам в PDF. Для HTML-ссылок используется отдельный YAML-параметр `html-base-uri`; внутренние ссылки `#якорь` не дополняются префиксом.
- `--html-base-img=PREFIX` — добавить префикс к относительным URL изображений в HTML; абсолютные URL не меняются.
- `--lnk-fmt` / `--no-lnk-fmt` — включить или отключить замену `.md` на `.html` либо `.pdf` в относительных ссылках с непустым якорем; по умолчанию отключена.
- `--toc-noh1` / `--no-toc-noh1` — исключить или включить H1 в оглавление; по умолчанию H1 включены.
- `--toc-hmax=N` — максимальная глубина оглавления от 1 до 6; по умолчанию 6. Значение вне диапазона ограничивается границей, нечисловое значение игнорируется.
- `--page-number` / `--no-page-number` — включить или отключить номера страниц PDF; по умолчанию отключены. Номера в PDF-оглавлении показываются независимо от этой настройки.

В начале исходного файла можно указать YAML-подобный блок:

```yaml
---
title: "Пример"
author: "Автор"
geometry: margin=20mm margin-left=25mm
html-base-img: ../
lnk-fmt: true
toc-noh1: false
toc-hmax: 4
page-number: true
---
```

`geometry` управляет полями PDF (`margin`, `margin-left`, `margin-right`, `margin-top`, `margin-bottom`); значения можно задавать в `mm`, `cm` или пунктах. Для HTML дополнительно доступны `html-base-uri` и `html-template`. Параметры `title` и `author` используются в метаданных PDF и, если заданы соответствующие подстановки, в HTML-шаблоне. Настройки `lnk-fmt`, `toc-noh1`, `toc-hmax`, `page-number` и `html-base-img`, явно указанные в CLI, переопределяют одноимённые значения из блока документа.

В HTML относительные URL изображений и ссылок оцениваются относительно конечного HTML-файла; при иной структуре каталогов используйте `html-base-img` и `html-base-uri`. В PDF локальные файлы изображений ищутся относительно источника или `--root-dir`. Наличие другого Markdown-документа и его заголовков при конвертации ссылок не проверяется.

Подробный синтаксис описан в [руководстве по Markdown](markdown.md), ограничения — в [unsupported.md](../unsupported.md).
