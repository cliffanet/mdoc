# Формат данных для выходного модуля

## Массив текстовых элементов

В блоках содержимого часто встречается термин "массив текстовых элементов".

Это абзац из различных текстовых составляющих, являющиеся частью этого абзаца:

- Объект Str - стандартный текст,
- хеш, где поле 'type' указывает тип элемента:
    - bold (text - массив подэлементов),
    - italic (text - массив подэлементов),
    - strike (text - массив подэлементов),
    - underline (text - массив подэлементов),
    - mark (text - массив подэлементов),
    - escape (text - экранированный ASCII-знак пунктуации),
    - inlinecode - цитата в виде элемента внутри абзаца (str - содержимое),
    - image - изображение (url, text [необязательное], alt [необязательное], title [необязательное]);
        разрешённое ссылочное изображение содержит исходный text и простой видимый alt
    - href - ссылка (text - массив подэлементов, url, title [необязательное])

Временные inline-элементы badge заменяются парсером на разрешённые image или
буквальный текст неизвестной метки. Блочные badgedef сохраняются в дереве и по умолчанию
игнорируются базовым выходным модулем.


## Блоки

Вызываются одноимёнными методами, в которые передаются аргументы.

### modifier

Модификаторы разметки страницы.

* name - имя модификатора:
    * pagebreak - разрыв страницы
    * toc - оглавление; поле content содержит список элементов с deep, id и title

Модификаторы center и vcenter не передаются выходному модулю отдельными элементами:

* center задаёт полю align следующего текстового абзаца значение c,
* vcenter задаёт полю valign следующего текстового абзаца значение c.

Оба модификатора можно объединять в любом порядке и повторять. Пустые строки
между модификатором и абзацем игнорируются. Любой следующий элемент, кроме text,
считается синтаксической ошибкой.

### header

Заголовок.

* deep - глубина вложенности: 1 - самый верхний уровень,
* id - уникальный идентификатор заголовка для ссылок,
* content - массив текстовых элементов.

### listitem

Элемент списка.

* mode - тип списка:
    * ord - нумерованный
    * символ "*" или "-" - с указанным символом перед списком
* num - номер элемента для нумерованного списка,
* title - заглавное содержимое элемента списка (массив текстовых элементов), первый абзац,
* content - вложенное содержимое (массив текстовых элементов).

### badgedef

Определение ссылочного изображения.

* code - исходная метка,
* url - адрес изображения,
* title [необязательное] - подсказка.


### hline

Горизонтальная линия.

* title [необязательное] - текст заголовка (массив текстовых элементов).

### table

Таблица.

* mode - тип таблицы
    * 1 - стандартная с вертикальными разделителями колонок
    * 2 - облегчённая, только горизонтальные разделители рядов
* width - массив ширины колонок,
* align (только для типа "1") - массив выравниваний в колонках:
    * l - left,
    * c - center,
    * r - right,
    * пустая строка - выравнивание не указано
* hdr (только для типа "1") - массив с текстом в заголовках, каждый заголовок - массив текстовых элементов
* row - массив строк, в каждой строке массив ячеек, каждая ячейка - массив текстовых элементов

### code

Блок кода.

* lang (усли указан) - язык, которым должен подсвечен синтаксис
* text - массив строк (хеши: row, col, str).

### quote

Цитируемый блок.

* content - вложенное содержимое (массив текстовых элементов).

### textblock

Вложенный текстовый блок.

* text - массив строк (хеши: row, col, str).

### text

Абзац.

* text - массив текстовых элементов,
* align [необязательное] - горизонтальное выравнивание; c - по центру,
* valign [необязательное] - вертикальное выравнивание; c - последняя постраничная
    часть абзаца по центру оставшейся области PDF-страницы.
